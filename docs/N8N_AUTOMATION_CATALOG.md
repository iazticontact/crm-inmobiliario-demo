# NowCRM — n8n Automation Catalog

This catalog documents the automation workflows available in NowCRM. Each workflow is triggered by a CRM event via webhook and runs in n8n (self-hosted or cloud).

NowLabs AI recommends activations based on live CRM state — these recommendations map to the slugs below.

---

## Integration requirements

All n8n workflows receive events via:

```
POST https://your-n8n-instance.com/webhook/{workflow-slug}
Authorization: Bearer {N8N_API_KEY}
X-NowCRM-Workspace: {workspace_id}
```

Required env vars on the NowCRM side:

```
N8N_BASE_URL=    # Your n8n instance URL
N8N_API_KEY=     # n8n API key — server-side only, never exposed to browser
```

## Workflow catalog

---

### 1. `nowcrm-bienvenida-cliente`

**Trigger**: New client created in NowCRM  
**Actions**:
- Send WhatsApp welcome message via Meta Cloud API
- Attach PDF proposal (generated by `/api/documents/proposal`)
- Create onboarding task in CRM

**Payload**:
```json
{
  "event": "client.created",
  "workspace_id": "...",
  "client": { "id": "...", "name": "...", "phone": "...", "email": "..." }
}
```

---

### 2. `nowcrm-recordatorio-factura-vencida`

**Trigger**: Invoice marked as `overdue` (or scheduled daily check)  
**Actions**:
- Send WhatsApp reminder to client
- Send internal Slack/email alert to workspace owner
- Create follow-up task in CRM

**Payload**:
```json
{
  "event": "invoice.overdue",
  "workspace_id": "...",
  "invoice": { "id": "...", "client_name": "...", "amount": 0, "due_date": "..." }
}
```

---

### 3. `nowcrm-seguimiento-lead-caliente`

**Trigger**: Client lead_score ≥ 70 AND no contact in 48h  
**Actions**:
- Send internal alert (email or Slack) with client profile + score
- Auto-schedule a follow-up task if none exists

**Payload**:
```json
{
  "event": "lead.hot_no_contact",
  "workspace_id": "...",
  "client": { "id": "...", "name": "...", "lead_score": 0, "last_contact": "..." }
}
```

---

### 4. `nowcrm-confirmacion-cita`

**Trigger**: Calendar event created or updated  
**Actions**:
- Send WhatsApp confirmation to client with date/time
- Add Google Calendar event (requires Google Calendar integration)
- Send reminder 24h before via WhatsApp

**Payload**:
```json
{
  "event": "calendar_event.created",
  "workspace_id": "...",
  "event_data": { "id": "...", "title": "...", "date": "...", "client_name": "...", "client_phone": "..." }
}
```

---

### 5. `nowcrm-propuesta-lead-caliente`

**Trigger**: Client status changes to `lead` with score ≥ 80  
**Actions**:
- Generate PDF proposal via NowLabs AI
- Send via WhatsApp with personalized message
- Create task: "Follow up on proposal"

**Payload**:
```json
{
  "event": "client.lead_score_high",
  "workspace_id": "...",
  "client": { "id": "...", "name": "...", "lead_score": 0, "email": "..." }
}
```

---

### 6. `nowcrm-alerta-diaria`

**Trigger**: Scheduled — every day at 8:00 AM  
**Actions**:
- Query CRM: overdue invoices + hot leads + upcoming events
- Send daily briefing via WhatsApp to workspace owner

**Payload**:
```json
{
  "event": "scheduled.daily_briefing",
  "workspace_id": "...",
  "date": "2026-05-14"
}
```

---

### 7. `nowcrm-escalado-urgente`

**Trigger**: Invoice overdue > 30 days OR lead_score drops below 30 after being high  
**Actions**:
- Escalate to workspace owner via WhatsApp + email
- Flag client with `urgent` tag in CRM

**Payload**:
```json
{
  "event": "alert.escalation",
  "workspace_id": "...",
  "reason": "invoice_overdue_30d | lead_score_drop",
  "client": { "id": "...", "name": "..." }
}
```

---

**Trigger**: Invoice status changes to `paid`  
**Actions**:

**Payload**:

### 10. `nowcrm-resumen-semanal`

**Trigger**: Scheduled — every Monday at 9:00 AM  
**Actions**:

## Triggering workflows from NowCRM

Workflows are triggered from `/api/agent/tool` or from dedicated event hooks when an action is confirmed in the UI. The trigger call looks like:

```typescript
await fetch(`${process.env.N8N_BASE_URL}/webhook/${slug}`, {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${process.env.N8N_API_KEY}`,
    'X-NowCRM-Workspace': workspaceId,
  },
  body: JSON.stringify(payload),
})
```

---

## Security notes

- `N8N_API_KEY` is server-side only — never referenced in client components
- Each workflow validates `X-NowCRM-Workspace` to prevent cross-tenant calls
- n8n credentials (WhatsApp token, Google OAuth) are stored in n8n's encrypted credential store — not in NowCRM's env
- Webhook URLs are not publicly documented in the UI — configure via n8n admin panel
